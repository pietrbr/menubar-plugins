# tools

`plugins/tools.sh` shows a menu of small tools. In SwiftBar, the menu bar icon is the SF Symbol `wrench.and.screwdriver`.

## Tools

Count clipboard: shows a notification with the number of characters, words, and lines in the clipboard text. Characters include spaces and line breaks. A last line without a line break counts as a line.

## Notifications

The plugin sends notifications with `osascript`, so macOS shows them as notifications from Script Editor. If no notification appears, open System Settings > Notifications and allow notifications for Script Editor.
